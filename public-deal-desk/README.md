# Mac2MacOnline Public Deal Desk (PDD)

This directory contains the approved Public Deal Desk source snapshot.

- Public deals load from Supabase.
- Bids remain confidential.
- Supporting files upload to a private Supabase Storage bucket.
- Shopify Draft Order creation remains disabled until private Shopify credentials are configured.
- Run `supabase/pdd-setup.sql` once in the Supabase SQL Editor before accepting live bids.

The current Sites deployment remains the production review surface. This GitHub copy is the approved source backup and integration branch.
